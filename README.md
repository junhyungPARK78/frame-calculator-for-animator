# 프레임 계산기 (Frame Calculator)

애니메이션 작업용 프레임/타임코드 계산기 Chrome 확장 프로그램입니다.

기존 구글 시트 기반 도구에서 소수점 표기 혼동(`4.70` → 4초 7프레임? 4초 70프레임?) 문제를 해결하기 위해 제작했습니다.

---

## 기능

- **다양한 입력 형식 지원**: `1+12` / `1.12` / `1 12` 모두 1초 12프레임으로 파싱
- **FPS 지원**: 24 / 30 / 60 및 커스텀 FPS
- **실시간 합계**: 선택한 행 또는 전체 행의 합계를 초+프레임 / 소수점 초로 표시
- **프로젝트 관리**: 여러 프로젝트를 이름별로 저장·불러오기
- **Import / Export**: 프로젝트를 JSON 파일로 내보내거나 가져오기
- **자동 저장**: Chrome Storage Sync에 자동 저장 (용량 초과 시 Local로 폴백)
- **다크 / 라이트 모드** 전환

---

## 설치 방법

1. 이 저장소를 클론하거나 ZIP으로 다운로드합니다.
2. Chrome 브라우저에서 `chrome://extensions` 를 엽니다.
3. 우측 상단 **개발자 모드**를 활성화합니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼 클릭 후 `output/` 폴더를 선택합니다.

---

## 입력 형식

| 입력 | 의미 |
|------|------|
| `1+12` | 1초 12프레임 |
| `1.12` | 1초 12프레임 |
| `1 12` | 1초 12프레임 |
| `36` | 36프레임 (숫자만 모드: 프레임) |
| `36` | 36초 (숫자만 모드: 초) |
