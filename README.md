# 프레임 계산기 (Frame Calculator)

[한국어](README.md) | [日本語](README.ja.md) | [English](README.en.md)

애니메이션 작업용 프레임/타임코드 계산기 Chrome 확장 프로그램입니다.

기존 구글 시트 기반 도구에서 소수점 표기 혼동(`4.70` → 4초 7프레임? 4초 70프레임?) 문제를 해결하기 위해 제작했습니다.

![preview](assets/preview.ko.png)

---

## 설치 방법

1. 이 저장소를 클론하거나 ZIP으로 다운로드합니다.
2. Chrome 브라우저에서 `chrome://extensions` 를 엽니다.
3. 우측 상단 **개발자 모드**를 활성화합니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼 클릭 후 `output/` 폴더를 선택합니다.

---

## 입력 형식

소수점, 플러스, 띄어쓰기 방식을 모두 지원합니다.

| 입력 | 의미 |
|------|------|
| `1+12` | 1초 12프레임 |
| `1.12` | 1초 12프레임 |
| `1 12` | 1초 12프레임 |
| `.12` / `0.12` | 0초 12프레임 (항상 프레임으로 처리) |
| `36` | 36프레임 또는 36초 (숫자만 모드 설정에 따라) |

- 프레임 값이 FPS 이상이면 자동으로 초로 올림 (예: 24fps 기준 `0+26` → `1+02`)

## 기능

### FPS 설정
- **프리셋 버튼**: 24 / 30 / 60
- **커스텀 FPS**: 자연수 1~99 직접 입력

### 숫자만 입력 시 모드
숫자 하나만 입력했을 때 프레임으로 처리할지 초로 처리할지 선택합니다.
- `프레임` 모드: `5` → 0초 5프레임
- `초` 모드: `5` → 5초 0프레임

### 테이블
- **컷 번호**: 행 순서에 따라 자동 부여
- **sec.frame 입력**: 위 입력 형식으로 자유롭게 입력
- **초 (sec)**: 입력값을 소수점 초로 환산하여 표시
- **누적 행 (∑)**: 테이블 하단에 전체 합계를 `초+프레임` 및 소수점 초로 표시
- **앞자리 0**: 프레임 숫자 앞자리 0 표시 여부 선택 (`5+03` ↔ `5+3`)

### 행 관리
- **행 추가**: 하단 버튼 또는 마지막 행에서 Enter 키
- **행 삽입**: 각 행의 `+` 버튼으로 해당 행 아래에 삽입
- **행 삭제**: 각 행의 `×` 버튼 (2행 이상일 때 표시)
- **Enter 키**: 다음 행으로 포커스 이동, 마지막 행이면 새 행 추가

### 행 선택 및 부분 합계
- **체크박스**: 개별 행 선택
- **Shift + 클릭**: 범위 선택
- **전체 선택 / 전체 해제**: 헤더 버튼
- 행을 선택하면 하단 합계가 **선택 행만의 합계**로 전환

### 프로젝트 관리
- **저장**: 이름 입력 후 저장 버튼 또는 Enter
- **불러오기**: 드롭다운에서 저장된 프로젝트 선택
- **삭제**: `✕` 버튼으로 현재 프로젝트 삭제
- **자동 저장**: 입력 필드에서 포커스가 벗어날 때 자동 저장

### 저장 구조
- **Chrome Storage Sync** 우선 저장 — Chrome 계정으로 여러 PC 간 자동 동기화
- 동기화 용량(항목당 8KB) 초과 시 **Chrome Storage Local**로 자동 폴백
- 용량 초과 프로젝트는 테이블 위에 경고 배너 표시

### Import / Export
- **내보내기**: 현재 프로젝트를 JSON 파일로 저장
- **전체 내보내기**: 모든 프로젝트를 JSON 하나로 저장
- **가져오기**: JSON 파일을 불러와 병합 (같은 이름은 덮어씀)

### 화면 설정
- **다크 / 라이트 모드** 전환 (🌙 / ☀️ 버튼)
- **언어 전환**: KO / JA / EN
